# Agent Note: 引用已提交的产物,绝不引用设计会话序号

Status: implemented

[English](2026-08-31-committed-artifact-citations.md) | 中文

## 问题

大型设计与评审会话会留下工作速记——决策序号、审计条目代号、计划章节编号、评审人裁定。这些速记在会话 transcript(文本记录)还开着时读起来顺理成章,一旦关闭就什么也解析不到。本仓库几乎完全由 coding agent 跨多个会话开发,风险是结构性的而非偶然的;[dsh-trim-cot-leakage](../../../skills/dsh-trim-cot-leakage/SKILL.md) 技能的分类法描述了这些模式族。[文档标准](../../../../docs/AGENTS.md)禁止变更叙事("previously"、PR 引用),但在本笔记之前没有写下引用规则,而本仓库也没有任何已提交的记录来说明它遵循的引用规则。

## 决策

本仓库采用上游 harness 的引用规则作为自己的规则,并按本语料校准:持久行文——注释、JSDoc、文档、笔记、测试注释与测试标题——只引用已提交的产物,无需 grep 考古即可在仓库内解析:

- 点名归属的 Agent Note(其路径在每个文件里至少出现一次,行内用可检索的名称)、文档页面路径,或 GitHub issue 编号。PR、commit、分支与栈位置依[文档标准](../../../../docs/AGENTS.md)在文档与代码中仍被禁止;issue 是持久且可引用的,Agent Note 可引用已合并的 PR 与 issue 作为证据。
- 决策有已提交归属文档的设计会话序号,替换为该决策的名称与归属笔记路径。没有归属文档的序号予以删除,其事实性语句改写为可独立成立的表述。
- 已修复的回归以现在时反事实句固定下来("没有 X 就会发生 Y"),绝不写成仓库历史("过去曾 Y")。
- 冻结树不受此约束:已录制的模型输出、金标夹具、`.agents/notes/archived/` 与 `docs/archive/` 保持原有行文。在笔记的变更故事段落内,历史阶段名称("首版交付了 X")符合只描述当前状态的要求;"this cut" 这类指示当前版本的标记在任何地方都仍被禁止。
- 写作语言残留检索仅在另一语言的行文表面运行,不把整个中文语料库当作未翻译残留;本仓库文档以中文为主,[召回检索](../../../skills/dsh-trim-cot-leakage/references/recall-batteries.md)双向运行。
- 模型或用户可见的文字,只有归属行为证据(测试或金标夹具)在同一次变更中更新时才改;否则审计保持原文并报告推迟项。

上游清理笔记——[引用已提交的产物(harness)](../../../../../deepseek-harness/.agents/notes/implemented/process/2026-08-09-committed-artifact-citations.md)——持有该规则的完整理由与全仓库清理证据;本笔记记录的是采纳,[dsh-trim-cot-leakage 技能](../../../skills/dsh-trim-cot-leakage/SKILL.md)把这些规则在本仓库落地为可执行工作流。

## 曾考虑的替代方案

- **逐字翻译上游笔记,而不是写一篇适配笔记。**不予采纳:上游的问题段描述的是 harness 专属表面(生成目录、typert 页面),本仓库并不存在;不适配的副本会陈述本仓库并不运行的门禁(`verify-type-equiv`、配对合并驱动)的后果。
- **为被禁词汇建一道机械门禁。**暂缓,与上游相同:这类词汇是无界的自然语言,需要人工判断才能把泄漏与正当行文区分开。若本仓库再次出现该模式,技能中的召回检索位居候选清单之首,用于构造一道窄而高查准的检查。
- **不写笔记,只在技能里携带这条规则。**不予采纳:技能是工作流,不是决策记录;notes 树才是本仓库"为什么"的家,且 trim 技能的 REQUIRED BACKGROUND 链接必须能解析到一篇归属记录。

## 后果

- 本仓库的注释与文档凭路径或名称引用;读者永远不必为追溯一条引用而重建已关闭的会话。
- 设计会话必须先把决策落进 Agent Note,持久行文才能引用这些决策;序号速记只留在会话内部。
- 引用变长了(用一条笔记路径取代"(decision 21)"),换来的是无需 grep 即可解析。
- 没有门禁会拒绝新的序号引用——这条规则由评审把关,按 [dsh-code-review](../../../skills/dsh-code-review/SKILL.md) 执行。
